# openGym for Home Assistant

Home Assistant app (add-on) that runs [openGym](https://opengym.ch), a self-hosted gym and
body-weight tracker.

Add this repository in Home Assistant: Settings → Apps → ⋮ → Repositories →
`https://github.com/armandkamffer/homeassistant-opengym-app`, then install **openGym**.

See [opengym/DOCS.md](opengym/DOCS.md) for HTTPS/passkey setup. Unofficial; openGym is by
Duarte Santos (AGPL-3.0).
